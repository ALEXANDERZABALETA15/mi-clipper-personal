
# Mi Clipper Personal

Software personal desarrollado en Python y Streamlit para descargar videos, analizar su audio y generar clips automáticamente.

## Funcionalidades actuales

- Descarga de videos mediante yt-dlp.
- Extracción de audio con FFmpeg.
- Análisis de audio con Librosa y NumPy.
- Generación automática de clips.
- Duración configurable.
- Cantidad de clips configurable.
- Reproducción, guardado y descarte de clips.

## Tecnologías

- Python
- Streamlit
- FFmpeg
- yt-dlp
- Librosa
- NumPy

## Instalación

1. Clonar el repositorio.
2. Crear un entorno virtual.
3. Instalar dependencias:

pip install -r requirements.txt

4. Instalar FFmpeg y verificar que esté disponible en PATH.

5. Ejecutar:

streamlit run app.py
